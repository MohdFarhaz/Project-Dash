        How to update this dashboard every month (no coding)
        1. In Excel, finish the tracker. The green banner on the P&L Dashboard sheet must say all entries are complete. Press Ctrl+S so the calculated values are saved.
        2. Copy the new rows of P&L ENTRY as values and save them as a CSV file. Keep the same column headings.
        3. In Supabase open Table Editor → P&L ENTRY → Insert → Import data from CSV and add the new rows. Keep slno unique (continue after the last number).
        4. Open this page again (or refresh it). The same link shows the new data to everyone. Check the Data quality section.
